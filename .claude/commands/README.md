# .claude/commands

Slash commands. Write `/new-item` first — authoring ~780 items is the real project, and you will
run it hundreds of times.

| File | Command | Purpose |
|---|---|---|
| `new-item.md` | `/new-item <stage> <objective>` | Author an item in house style, distractors from named misconceptions, `status='draft'` |
| `new-stage.md` | `/new-stage <id>` | Scaffold `content/stages/NN.md`, objectives with level + competency, blueprint entry |
| `audit.md` | `/audit` | `run_invariants()` + denial matrix + bundle scan + report |
| `a11y.md` | `/a11y` | axe on changed routes × three themes, plus the 12 accent presets |
| `regrade.md` | `/regrade <item>` | Key-correction workflow with audit log entries |
