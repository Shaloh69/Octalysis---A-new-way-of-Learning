# The Sort (a moon's classification encounter): template source

`template.png`: **Stardew Valley, the chest screen**, from
https://interfaceingame.com/screenshots/stardew-valley-chest/ (HTTP 200), image
https://interfaceingame.com/wp-content/uploads/stardew-valley/stardew-valley-chest-1920x1080.png
(HTTP 200, image/png, 973,306 bytes, 1920×1080). Captured 30 Sep 2026 with
curl, the same source and method as `_direction/biome/` (see
`_direction/SOURCE.md`). **Opened before use.**

What it shows, and what is taken:

| In the template | Taken as |
|---|---|
| Two framed containers over the live world, one above the other | The two columns, **Architecture** and **Organization**, framed in the planet's sprites, over the biome |
| The player's own inventory below, where items start | **To sort**: the cards not yet placed |
| An item moved between containers | A card moved to a column, and back |
| The tooltip: name, category, a sentence | After **Compare with the book**: each card with the book's column and the book's own sentence |
| The OK button, one confirming action | **Compare with the book**, the one action that reveals anything |

Not taken: drag as the only way to move an item (every move here is a button,
so it works by keyboard and by tap), the colour swatches, the tool icons.

Copyright: a screenshot of a commercial game, kept as a reference artifact
only, as the other templates are. Nothing from it ships.
