# The arrival screen: template source

`template.png`: **Starfield, a loading screen**, from
https://interfaceingame.com/screenshots/starfield-loading-2/ (HTTP 200), image
https://interfaceingame.com/wp-content/uploads/starfield/starfield-loading-2.png
(HTTP 200, image/png, 529,420 bytes, 1920×1080). Captured 2 Oct 2026 with
curl. **Opened before use.**

**Rejected, each looked at:** `starfield-loading` (a black frame with a ring,
3 KB: nothing to learn from), `no-mans-sky-loading` (a subtitle line over a
scene, no facts about the place), `halo-infinite-loading-2` (a title over a
landscape, no facts). `destiny-2-loading`'s image did not resolve from its page.

| In the template | Taken as |
|---|---|
| The place you are arriving at, filling the screen | The planet's own biome art, filling the screen (no globe, no veil: instructor, 2 Oct 2026) |
| Bottom-left: an emblem, a name and a level | The stage or moon number as a badge; "Entering"; the world named ("a banded gas giant"); the stage's title |
| A rule, then one line of lore about the setting | The brief's line about this kind of world, quoted |
| A loading ring bottom-right | A ring, and Continue, with "Press any key" |

**Ours:** the facts list (the frost line, the moons, the levels, the grading
period), all quoted from the instructor's brief or built from the planet's own
data (`solar-system/world.ts`). The caption is the planet's sprite panel, so
its words wear the biome's checked inks.

Copyright: a screenshot of a commercial game, kept as a reference artifact
only. Nothing from it ships.
